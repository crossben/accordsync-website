# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on <https://github.com/crossben/accordsync>. Do not open a
public issue.

Include what you found, how to reproduce it, and the version (or commit) affected. You will get an
answer as soon as possible; fixes are released as patch versions and credited unless you prefer
otherwise.

## Supported versions

Accord is pre-1.0. Only the latest release receives fixes.

## How Accord is secured

See [docs/security.md](docs/security.md): what the server enforces, and what you must configure
when you deploy it.
