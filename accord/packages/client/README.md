# @accordsync/client

The Accord client: local-first writes, background sync, conflict API, IndexedDB and SQLite storage.

Part of **[Accord](https://github.com/crossben/accordsync)**, offline-first sync that stays correct when
the network lies. See [docs/client.md](https://github.com/crossben/accordsync/blob/main/docs/client.md).

```sh
npm install @accordsync/client
```
