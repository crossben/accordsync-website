# @accordsync/server

The Accord sync server: `accord serve` with a TypeScript config, JWT auth, scoped push/pull over PostgreSQL.

Part of **[Accord](https://github.com/crossben/accordsync)**, offline-first sync that stays correct when
the network lies. See the [README](https://github.com/crossben/accordsync#run-a-server) and [docs/protocol.md](https://github.com/crossben/accordsync/blob/main/docs/protocol.md).

```sh
npm install @accordsync/server
```
