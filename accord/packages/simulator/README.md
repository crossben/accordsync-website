# @accordsync/simulator

Deterministic network and device simulator used to prove Accord converges under dropped, delayed, duplicated and reordered messages.

Part of **[Accord](https://github.com/crossben/accordsync)**, offline-first sync that stays correct when
the network lies. Useful to test your own scope rules and schemas under faults; see `convergence.test.ts` in the repository.

```sh
npm install @accordsync/simulator
```
